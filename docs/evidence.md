## Evidence capture guidance

Screenshots must never expose credentials, tokens, passwords, private keys, kubeconfig contents, or application secrets. Redact sensitive values before capture rather than relying on later image editing.

Terminal screenshots should include enough command and output context to identify what was run, which resource was inspected, and whether the result succeeded. Crop unrelated desktop content while retaining the evidence needed to evaluate the claim.

Use descriptive filenames grouped by area so future evidence remains discoverable and can be linked without guessing.
